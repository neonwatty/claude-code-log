This is the standard layout with header, sidebar, main content, and footer. The sidebar is responsive and collapses to a mobile-friendly format on smaller screens.

📱 Mobile Responsiveness

On mobile devices (< 640px), the sidebar stacks vertically and the layout becomes mobile-first. Navigation transforms to a hamburger menu.
